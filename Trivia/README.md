# みどころ・怪奇・都市伝説の文

市区町村シートの「みどころ」カードと「怪奇・都市伝説」カードの文です。市区町村マスタ `LocalGovernmentCodeJapan_Knowledge.csv` の「豆知識(有名なもの)」(みどころ)と「豆知識(歴史)」(怪奇・都市伝説)の列に入ります。みどころの最初の一文は、初訪問の通知の本文にもそのまま使われます。

2026-11-15〜16にユーザーと決めた書き方で、全1,918市区町村を作り直します。お手本は `Trivia/out/b00_examples.json`(渋谷区・新宿区・中央区・横浜市・岡崎市・西尾市・尾張旭市。ユーザー確認済み)です。書く前に必ず読んで、文の調子を合わせてください。

## 書き方

**共通**

- 1枚のカードに話は一つ。名所を並べない(名所の一覧は「この街でできること」が受け持つ)。
- 最初の一文だけで「へえ」となるようにする。40字くらいまで(最大50字)で、単独で読める文にする。
- 二文目以降で「なぜそうなのか」を短く書き、最後はその街のどこで確かめられるか(碑・神社・通り・お店など)で締める。
- 全体で130〜160字(100〜190字に収める)。
- 口調は「だ・である」の読みもの調。体言止めや「――」で余韻を出してよい。
- 事実は年・人名・数字まで確かめられるものだけ。言い伝えは「〜と伝わる」「〜という説がある」と書き分ける。営業時間・料金・混雑は書かない。閉業・閉館した場所を今もあるように書かない。

**みどころ(highlight)**

- 地名の由来、「日本初」、名物の意外なルーツ、景色に隠れた仕掛けなど、誰かに話したくなる事実。
- 「〇〇、△△が定番」のような羅列は書かない。
- 政令指定都市は、市の行には市全体の話、区の行にはその区ならではの話を書き、同じ話を使い回さない。

**怪奇・都市伝説(legend)**

- 実在して、ネットで実際に有名な怪談・都市伝説・言い伝えだけを書く。実在の事件や心霊スポットが題材でもよい。
- 一番怖い場面・不思議な場面から始め、なぜそう語られるのかを続ける。立入禁止の場所は「立入禁止」と添える。
- 有名な話が無い街は、関係ない事実で埋めず、次の一文だけにする(市区町村名はマスタの表記のまま):
  `〇〇には、特に有名な怪談・都市伝説はありません。`
- 怪談をでっちあげない。検索で同じ話が複数のサイトに出てこなければ「有名」とは言えないので、上の一文にする。

## 作り方(スケジュール実行の1回分)

1回で1バッチ(約48市区町村)を作る。計画は `Trivia/plan.json`(40バッチ)。

1. 作業ブランチ `claude/project-thread-4nmqmc` を最新にする(`git fetch origin claude/project-thread-4nmqmc && git checkout -B claude/project-thread-4nmqmc origin/claude/project-thread-4nmqmc`)。
2. `python3 Trivia/scripts/next_batch.py` で次のバッチを出す。「全バッチ完了」なら何もせず終わる。
3. 市区町村ごとに材料を集める。
   - 今の文(出力の[今の…])は材料として使ってよいが、事実は確かめ直す。
   - 都市伝説: `WebSearch` で「<都道府県><市区町村> 心霊」「<市区町村> 都市伝説 怪談」などを1〜2回検索し、同じ話が複数のサイトに出てくるか確かめる。
   - みどころ: ja.wikipediaの記事(出力のURL。候補が2つあるときは両方渡し、開けた方を使う)を、web-fetchエージェントで読む。URLはパーセントエンコードのまま渡す。1回の呼び出しに5市区町村分くらいのURLをまとめ、「地名の由来・名物の起源・日本初・伝説・意外な事実を、年や数字ごと短く抜き出して」と頼む。
4. `Trivia/out/bNN.json`(NNはバッチ番号2桁)に `{"行政区域コード": {"highlight": "...", "legend": "..."}}` の形で書く。途中で止まってもよいように、10市区町村ほど書くごとに保存する。
5. `python3 Trivia/scripts/merge_trivia.py --check` で確かめ、出た問題を直す。通ったら `python3 Trivia/scripts/merge_trivia.py` でマスタへ書き込む。
6. 変更は `Trivia/out/bNN.json` と `LocalGovernmentCodeJapan_Knowledge.csv` だけ。コミットして `git push origin claude/project-thread-4nmqmc` する。押し出しが拒否されたら `git pull --rebase origin claude/project-thread-4nmqmc` してマージをやり直してからプッシュする(CSVがぶつかったら、相手側を取ってから `merge_trivia.py` をもう一度実行する)。メッセージは `feat: みどころ・都市伝説を書き直す(バッチNN <最初の都道府県>〜)`。

やらないこと: アプリのコードの変更、マージ、TestFlightやApp Storeへのアップロード、依頼されていないバッチを先に進めること(1回1バッチ)。
