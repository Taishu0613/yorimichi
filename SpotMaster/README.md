# みどころマスタ

市区町村シートの「この街でできること」に出すみどころです。AIがさまざまな情報源から総合評価した結果を、市区町村ごとに最大10件、市区町村マスタ `LocalGovernmentCodeJapan_Knowledge.csv` の10列目「みどころ(JSON)」に入れます。アプリは起動時の同期でこの列をSwiftDataへ取り込み、シートでは読むだけです。アプリの中でAIも検索も動きません。

列の値はJSONの配列で、並び順がそのまま順位です。政令指定都市は、市の行と区の行のどちらにも入れます。

```json
[{"name":"千葉ポートタワー","category":"view","action":"港の景色を眺める","reason":"高さ125mの展望台から東京湾と街を一望できる"}]
```

| 項目 | 内容 |
|---|---|
| `name` | 施設・場所の名前。Appleマップ・Googleマップでそのまま検索するので、地図に載っている表記にする |
| `category` | `shrine` `temple` `castle` `history` `museum` `art` `garden` `view` `waterfront` `nature` `animals` `hotSpring` `park` `town` `food` `entertainment` `landmark` `other` のどれか（アイコンと、`action` が空のときの言葉を決める） |
| `action` | 何をするかの短い言葉（16字まで）。例: 港の景色を眺める。空でもよい |
| `reason` | おすすめの理由の一文（40字まで）。空でもよい |

## 作り方

1. `python3 -I SpotMaster/scripts/collect_evidence.py` で材料を集める（`SpotMaster/work/evidence/<都道府県コード>.json`）。材料はマスタの豆知識、Wikipediaの観光などの節、境界の中にあるWikidataの名所。
2. 下の指示でAIが市区町村ごとに評価し、`SpotMaster/work/spots/*.json` に `{"行政区域コード": [...]}` の形で書く。
   - `SpotMaster/lists/article_targets.md` の市区町村は、観光記事の検索結果も材料にする（1か所1回、全文は読まない）。
   - それ以外でも、みどころが3件に満たない市町村は同じように1回検索して補う。
3. `python3 SpotMaster/scripts/merge_spots.py SpotMaster/work/spots` でマスタへ書き込む。
4. `SpotMaster/scripts/check_spots.swift` で形式と実在を確かめる。「要確認」の行は名前を地図の表記に直すか、確かめられなければ別の場所に差し替えて、3からやり直す。

`SpotMaster/work/` は再生成できる作業用フォルダなのでGitに入れない。

## 入れないもの

- 座標。スポットはマップアプリで「名前＋市区町村名」を検索して開くので要らない（AIが作った座標のずれも避けられる）。
- MapKit・Googleの検索結果そのもの。Appleの規約で地図データの保存は一時的なものに限られ、Google Placesも場所IDを除き保存を禁じている。参考に見るのは構わないが、結果をそのまま書き写さない。
- 営業時間・料金・混雑など変わりやすい情報。閉業・閉園した場所。

## 評価の指示（AIに渡す文）

```text
材料を読み、市区町村ごとに、旅行者が寄り道する価値のある場所を最大10件、おすすめの順に選んでください。
- 材料とあなたの知識を照らし合わせ、一般的に有名な場所を優先する。Wikidataの数字は何言語のWikipediaに記事があるかで、有名さの目安にする（高層ビルや事務所のように、数字が高くても旅行者の目的にならないものは下げる）。
- 定番だけでなく、街の個性が分かる通りや商店街、新しい人気施設も入れる。
- 必ずその市区町村の中にあり、現在営業・公開している場所だけにする。実在に自信がない場所は入れない。良い候補が少なければ10件未満でよい。
- 同じ種類が並びすぎないようにする。同じ施設の部分（門や櫓など）を別々に数えない。
- 名前は地図に載っている表記にする。
- actionは「〜する」で終わる16字以内の言葉、reasonは40字以内の一文。材料の文を写さず、自分の言葉で書く。営業時間・料金・混雑は書かない。
```

## 確かめ方

`SpotMaster/scripts/check_spots.swift` が、形式の間違いと、名前で検索してその市区町村の境界の中に見つからない行を挙げます。使い方はファイルの先頭にあります。Wikidataで境界の中にあると分かっている名前は検索を省きます。検索の回数制限のため1件ごとに間を置くので、全国分は数時間かかります（`--format-only` なら形式だけをすぐ確かめられます）。

「要確認」は実在しないとは限りません（地図の表記が違うだけのことが多い）。
